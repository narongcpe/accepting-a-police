## สิ่งที่มีในต้นแบบ
**ฝั่งประชาชน**
- เข้าสู่ระบบด้วย ThaID (จำลอง: เลือกบุคคลทดสอบ) → เติมเบอร์โทร + ยืนยัน OTP (รหัสทดสอบ 123456)
- แจ้งเรื่อง 6 ขั้น: เช็กเหตุฉุกเฉิน (ส่งไป 191) → ประเภท → รายละเอียด/หลักฐาน → ผลคัดกรอง + เลือกโรงพักบนแผนผัง → เลือกวันเวลานัด → ยืนยัน (PDPA, ป.อ. ม.172–173)
- ได้เลขติดตาม `RP-<รหัสโรงพัก>-<ปีเดือน พ.ศ.>-<ลำดับ>` + QR Code
- ดูความคืบหน้า / ตรวจสถานะด้วยเลขติดตามโดยไม่ต้องล็อกอิน / ค้นหาโรงพักใกล้ที่สุด

**ฝั่งเจ้าหน้าที่**
- กล่องรับเรื่องเรียงตามความเร่งด่วน, ตัวกรอง, แจ้งเตือนเกิน SLA (สูง 24 ชม. / กลาง 72 / ต่ำ 168)
- รายละเอียดเรื่อง: รับเรื่อง, มอบหมาย พงส., ยืนยัน/เลื่อนนัด, ปรับระดับ (ต้องใส่เหตุผล), อัปเดตสถานะ, บันทึกภายใน/แจ้งผู้แจ้ง, ปิดเรื่อง/ส่งต่อ
- ซ่อนเลขบัตรประชาชน กดแสดงแล้วบันทึกลง audit log
- รายงานรายวัน/รายเดือน/รายปี + สรุปรายโรงพัก + ภาระงาน พงส. + คัดลอกเป็น CSV

## หน้าแรกและการค้นหาโรงพักด้วย GPS
- หน้าแรกเป็นเมนูไอคอน 3 ปุ่ม: ประชาชน / เจ้าหน้าที่ / ค้นหาโรงพักใกล้คุณ
- ปุ่ม "ใช้ตำแหน่งจากมือถือ (GPS)" ใช้ navigator.geolocation ของเบราว์เซอร์ ทำงานเมื่อเปิดผ่าน https เท่านั้น
  (เช่น ฝากไฟล์บน Netlify Drop หรือ GitHub Pages) ลิงก์พรีวิวของ Claude ปิดการแชร์ตำแหน่งไว้
- ถ้าขอตำแหน่งไม่ได้ จะมีตัวเลือกแตะบนแผนผัง เลือกจุดสำเร็จรูป หรือเปิด Google Maps ค้นหาโรงพักใกล้ฉัน
- ปุ่มนำทางเปิด Google Maps เส้นทางจากตำแหน่งปัจจุบันไปยังโรงพัก

## ข้อจำกัดของต้นแบบ
- ข้อมูลทั้งหมดเป็นตัวอย่าง เก็บใน localStorage ของเบราว์เซอร์ (ไม่มี server)
- พิกัดโรงพักเป็นค่าประมาณ ยังไม่ได้ตรวจสอบ
- ThaID, OTP, SMS เป็นการจำลอง
